> Origem do Python
    - Python nasceu em 1989 como um hobby, do programador Guido Van Rossum. A ideia inicial era dar continuidade a linguagem ABC, que era desenvolvida no CWI (Centro de pesquisa Holandês).
        -> Linguagem fácil e intuitiva
        -> Código aberto, para que todos possam contribuir
        -> Código inteligível quanto inglês
        -> Adequada para tarefas diárias, e produtiva!
    
    - Primeira versão  (1991)
        - Python 0.9.0 já tinha:
            - Classes, heranças, listas, strings, funções
            - tratamento de exceções
            - Módulos e imports
    
    - Python 1.0 (1994)
        - Chegou com map, filter, lambda
        - Funcionalidades que ainda usamos hoje

    - Python 2.0 (2000)
        - Coleta automática de lixo (gerencia memória sozinho)
        - List comprehensions
        - Unicode

    - Python 3.0 (2008)
        - Grande marco: Não era compatível com versão 2 (Quebrou códigos antigos de propósito)
        - Melhorias reais:
            - print virou função
            - divisão com resultado decimal
            - suporte melhor a unicode
        - Problema: Levou anos para todo mundo migrar
    
    - Mudanças pelo caminho
        - 2014: asyncio (programação assíncrona)
        - 2015: Tipos opcionais
        - 2020: Fim do suporte ao python 2

    - Atualmente:
        - Versão atual estável: Python 3.13
        - Usado em: web, dados, IA, automação, jogos, robôs, etc.
